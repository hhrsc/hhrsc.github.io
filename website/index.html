常见问题

Clipboard 会把数据上传到云端吗？

不会。当前版本没有云同步，剪贴板历史和密码库都保存在本机。

支持哪些内容？

支持文字、富文本格式和图片历史，也提供独立的本地加密密码库。

能自定义快捷键吗？

可以。你可以在设置中录制全局快捷键，具体可用组合受 Windows 注册规则约束。

安装包适用于什么平台？

当前安装包面向 64 位 Windows 桌面系统。

在哪里提交问题或建议？

可以前往 GitHub Issues，描述你的使用场景和期望结果。
