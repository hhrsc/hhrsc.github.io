Windows 剪贴板指南

Win + V 不够用时，先看你真正缺什么。

原生历史够轻便，复杂工作流才需要搜索、分类和格式转换。

下载 Clipboard 先看原生功能

本地优先，无需账户，当前版本不含云同步。

第一步

先用好 Windows 自带的 Win + V。

按 Win + V 可以打开剪贴板历史。它能保存最近复制的文字、HTML 和位图，也能固定常用项目，并可选择在设备之间同步。

微软当前说明中，历史最多保留 25 项，单项上限为 4 MB。重启设备后，未固定的历史会被清除。

查看微软官方说明

怎么选

轻量使用留在原生，重复工作交给工具。

不是功能越多越好。判断标准只有一个：它能不能减少你每天重复寻找、整理和转换内容的时间。

使用场景 Win + V Clipboard

不提供分类 适合

不提供 适合

值得安装的时刻

当“复制一下”开始变成一段工作流。

需要搜索与分类

按内容、类型和日期缩小范围，把高频片段固定或归类。

需要多格式复制

选取记录中的一段文字，再复制为 Markdown、HTML 或规整的单行文本。

希望内容留在本机

当前版本无需账户，不提供云同步。历史与本地密码库由你自己控制。

一句话结论

如果你只想找回刚刚复制的几条内容，先用 Win + V。
如果你每天都在找、分、改、重复复制，Clipboard 才会真正省时间。
