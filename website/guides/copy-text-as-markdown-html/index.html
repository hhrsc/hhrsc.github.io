不是每个人都需要再装一个剪贴板工具。

偶尔找回内容，用 Win + V。只做格式转换，PowerToys 很合适。历史越来越多，再考虑 Clipboard。

只做三件事。

打开记录，框选真正需要的文字，点击目标格式。原始记录不会因为这次转换而改变。

  1. 找到记录用关键词、类型或分类缩小范围。
  2. 选中文字一条长记录里，只框选这次要用的句子。
  3. 选择格式复制后直接粘贴到笔记、编辑器或表格。

格式转换在本机完成。

Clipboard 当前无需账户，也不提供云同步。剪贴板历史保存在本机，源码公开可查。
