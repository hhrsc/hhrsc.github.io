隐私说明

你的内容，
留在你的电脑里。

本说明适用于 Clipboard Windows 应用及其官方网站。生效日期：2026 年 9 月 1 日。

应用保存什么

应用会在你的 Windows 设备上保存剪贴板文字、图片、分类、设置以及你主动添加到密码库的内容。

密码库数据在本地加密保存。导出密码时，应用会明确提醒导出文件包含明文内容。

应用不会做什么

当前版本不要求账户，不提供云同步，也不在应用内投放广告或接入行为分析服务。

除非你主动导出、复制或分享内容，应用不会把剪贴板历史和密码库上传到我们的服务器。

你可以控制什么

你可以在应用内删除单条记录、清空历史、调整保留时间、停止剪贴板监听，或导出和导入支持的数据。

卸载应用前，如需保留数据，请先使用应用内提供的导出功能。

官网与下载

官网由 GitHub Pages 托管，安装包由 GitHub Releases 托管。GitHub 可能按照其隐私声明处理标准访问日志和下载请求。

本官网目前没有接入广告、用户画像或第三方访问分析脚本。

问题与反馈

如果你对隐私、数据处理或产品行为有疑问，请在公开仓库提交 Issue。请勿在 Issue 中粘贴密码或私密剪贴板内容。
